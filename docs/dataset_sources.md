# Dataset sources

## TrashNet

- **Repository:** [garythung/trashnet](https://github.com/garythung/trashnet)
- **Archive used:** [`data/dataset-resized.zip`](https://github.com/garythung/trashnet/blob/master/data/dataset-resized.zip)
- **License:** MIT License, as stated in the repository's [`LICENSE`](https://github.com/garythung/trashnet/blob/master/LICENSE) file (Copyright (c) 2017 Gary Thung).
- **Citation request:** The repository README asks users of the dataset to cite the repository.
- **Date added:** 2026-10-06
- **Selection:** Images were copied with the `trashnet_` prefix. The `trash` class was not used. A random sample of 500 images was selected from the combined paper and cardboard classes using seed `20261006`.

| `raw_images` category | Source class(es) | Images used |
| --- | --- | ---: |
| Plastic | plastic | 482 |
| Glass | glass | 501 |
| Can_Metal | metal | 410 |
| Paper | paper (299), cardboard (201) | 500 |

**Total used:** 1,893 images.
